# Design references

Terminal First StepsのStage 2デザイン判断に使った実在プロダクトの記録です。画面を模倣するためではなく、学習情報と入力環境の関係を比較するために保存しています。

取得日: 2026-08-28

## CMD Challenge

- URL: https://cmdchallenge.com/
- ローカルファイル: `cmdchallenge.png`
- 対象画面・状態: 最初の`hello_world`チャレンジ、未入力、PC幅
- 参考にする点: 課題、ヒント、入力欄が一画面内で近接し、説明後すぐ試せる構成。チャレンジ名と進捗を小さく示す方法。
- 採用しない点: 初心者には威圧感がある黒一色の画面、説明とエラーの少なさ、意味を学ぶより正解入力へ寄る構造。

## Linux Survival

- URL: https://linuxsurvival.com/linux-tutorial-introduction/
- ローカルファイル: `linux-survival.png`
- 対象画面・状態: Module 1 Introduction、未入力、PC幅
- 参考にする点: 説明と疑似ターミナルの並列配置、Page番号、先に試すコマンドを具体的に伝える構成。
- 採用しない点: 長大で常時表示されるサイドバー、狭い本文欄、現在のWebアプリとしては密度が高く古く見える青黒の配色。

## Codecademy — Learn the Command Line

- URL: https://www.codecademy.com/learn/learn-the-command-line
- ローカルファイル: `codecademy.png`
- 対象画面・状態: コース紹介のファーストビュー、PC幅
- 参考にする点: 太い見出し、番号、罫線、ドットパターンでコース構造を明快に見せる編集的な表現。学べる内容を短い一覧にする方法。
- 採用しない点: 販促バナー、評価・登録者数、会員登録導線など学習中には不要な情報。紫を主役にしたブランド表現。

## Terminal First Stepsへの反映方針

- 課題と入力欄を一画面内に保ち、入力後の意味を日本語で返す。
- ステップ番号と進捗は構造として使い、装飾だけの番号にしない。
- 現在地を「パスの路線図」として可視化し、移動の概念を記憶に残す。
- 全コマンドを常時並べず、必要なときだけ開けるコマンド手帳にする。
- 黒一色のハッカー表現ではなく、紙のフィールドノートと安全な計器盤を組み合わせる。

## 最終成果物の比較画面

- `final-desktop.png`: 1280 × 720 CSS px相当、初期状態。課題と入力環境の近さ、Path Rail、ファーストビュー内の入力欄を確認。
- `final-complete.png`: 1280 × 720 CSS px相当、コース完了状態。進捗、達成内容、再実行導線を確認。
- `final-mobile.png`: 375 × 812 CSS pxの検証枠、初期状態。横スクロールがなく、説明からターミナルへ自然に縦積みされることを確認。

比較の結果、参考元から採用した情報階層と即時実行性を保ちつつ、Terminal First Steps固有のPath Rail、冷たい鉱物色、信号オレンジ、紙と計器盤の対比へ置き換えています。
