# Terminal First Steps

ゼロからコマンドラインを学ぶためのWebアプリです。

## 目的

コマンドラインを初めて使う人が、ブラウザ上で手を動かしながら基本操作を身につけられる学習体験をつくります。

## 想定ユーザー

- ターミナルを使ったことがない人
- 開発学習を始める前に基礎を身につけたい人
- コマンド操作への苦手意識をなくしたい人

## 最小MVP候補

- ブラウザ内で安全に試せる疑似ターミナル
- 「移動・確認・作成」から始める短いステップ式レッスン
- 入力したコマンドへの即時フィードバックとヒント
- レッスンの進捗表示

## 現在の状態

今回はリポジトリと企画用READMEのみを作成しています。アプリコード、依存関係、設定ファイルはまだ実装していません。

## 次に確認したいこと

- 疑似ターミナルにするか、安全に隔離した実環境を使うか
- 主な利用端末と対応対象
- 最初のレッスン構成と画面イメージ
