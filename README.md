# Terminal First Steps

コマンドライン未経験者が、ブラウザ上の安全な疑似ターミナルで基本操作を学ぶ日本語Webアプリです。

## 状態

`repository-creator`のプロダクト工程に従い、Stage 1のコア実装・検証、Stage 2の完成後監査・拡充・Visual QA・再監査まで完了しています。

## できること

- 全8ステップのガイド付き入門コース
- `pwd`、`ls`、`cat`、`cd`、`mkdir`、`touch`、`clear`
- 実OSへ接続しない仮想ファイルシステム
- 入力結果の日本語フィードバックと段階式ヒント
- コマンドと引数を分けて理解できる「入力のしくみ」
- 現在地を路線図として示すPath Rail
- 7コマンドを確認できるコマンド手帳
- `localStorage`による進捗保存と確認付きリセット
- PC・スマートフォン対応、キーボード操作、reduced motion対応

## 実行方法

インストールやビルドは不要です。

1. リポジトリを取得する
2. `index.html`をブラウザで開く

ローカルサーバーを使う場合:

```bash
python3 -m http.server 8000
```

その後、`http://localhost:8000/`を開きます。

## 検証済み

- 8ステップのEnterキー完走
- 空入力、大文字、未対応コマンド、存在しない対象、重複作成
- `clear`、途中・完了状態の復元、リセット取消・確定
- 1280px幅の初期・完了画面
- 375px幅の横スクロールなし、ヒント・入力・コマンド手帳
- ブラウザコンソールの未処理エラーなし

## 意図的に含めないもの

実シェル、バックエンド、DB、認証、複数コース、自由練習、ランキング、決済、広告、Analytics、本番公開は現在の中心範囲外です。
