# Terminal First Steps

ゼロからコマンドラインを学ぶための、日本語の入門Webアプリです。ブラウザ上の安全な疑似ターミナルで、確認・移動・作成の基本を手を動かしながら学びます。

## 現在のフェーズ

`repository-creator`の正式なワークフローでプロダクト文書を同期し、Stage 1のCore Definitionまで完了しています。アプリコードはまだありません。

- 次の作業: 単一の`index.html`でコア実装を開始
- 実装範囲: フロントエンドのみ
- 実行方式: 実OSへ接続しない疑似ターミナル
- コア範囲: 1コース、全8ステップ、7コマンド

## コアの概要

- `pwd`、`ls`、`cd`、`mkdir`、`touch`、`cat`、`clear`
- 仮想ファイルシステム
- 日本語フィードバックとヒント
- `localStorage`による進捗保存と確認付きリセット
- PC推奨、スマートフォン操作可能
