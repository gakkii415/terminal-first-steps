# Terminal First Steps

ゼロからコマンドラインを学ぶための、日本語の入門Webアプリです。ブラウザ上の安全な疑似ターミナルで、確認・移動・作成の基本を手を動かしながら学びます。

## 現在のフェーズ

要件定義とMVP仕様が完了し、コードを書き始める直前です。

- アプリコード: 未実装
- 次の作業: 単一の`index.html`で最小MVPを実装
- 実装範囲: フロントエンドのみ
- 実行方式: 実OSへ接続しない疑似ターミナル

## MVPの概要

- 未経験者向けの1コース、全8ステップ
- `pwd`、`ls`、`cd`、`mkdir`、`touch`、`cat`、`clear`の7コマンド
- 入力への日本語フィードバックとヒント
- 仮想ファイルシステム
- `localStorage`による進捗保存とリセット
- PC推奨、スマートフォン対応

## 意図的に対象外としているもの

- 実際のシェルやサーバー上でのコマンド実行
- バックエンド、データベース、認証
- 複数コース、ランキング、自由練習
- 決済、広告、Analytics
- 本番公開

## 次の一手

`index.html`を作成し、静的な画面骨格、疑似コマンド、レッスン進行、保存とリセットの順に最小MVPを実装します。MVP完成後はレビューのために停止し、承認前にUI改善やバックエンド追加へ進みません。
