# MVP仕様

## 1. 実装方針

- 方式: ブラウザ内だけで動く疑似ターミナル
- 言語: 日本語
- 構成: 単一の`index.html`
- 保存: `localStorage`
- 外部依存: なし
- 実コマンド実行: なし

## 2. 基本画面

```text
┌─────────────────────────────────────┐
│ Terminal First Steps   3 / 8  [最初から] │
├─────────────────────────────────────┤
│ 今回のミッション                         │
│ 現在いる場所を確認してみよう               │
│ 説明・入力例・[ヒントを見る]               │
├─────────────────────────────────────┤
│ learner@terminal:~$ pwd             │
│ /home/learner                       │
│ learner@terminal:~$ [入力欄________] │
├─────────────────────────────────────┤
│ ✓ 現在地を確認できました                  │
└─────────────────────────────────────┘
```

- 上部: アプリ名、進捗、リセット
- 中部: 現在のステップ、目的、短い説明、ヒント
- 下部: 出力履歴、プロンプト、コマンド入力欄、フィードバック
- 完了時: 学んだ内容と「最初から復習する」ボタン

## 3. 初期仮想ファイルシステム

```text
/
└── home/
    └── learner/
        ├── welcome.txt
        └── projects/
```

- 初期カレントディレクトリ: `/home/learner`
- `welcome.txt`の内容: `ようこそ！ここは安全な練習用ターミナルです。`
- ユーザーが作成したフォルダとファイルは仮想状態にのみ保持する

## 4. 対応コマンド

| コマンド | MVPでの動作 | 主なエラー |
|---|---|---|
| `pwd` | 現在のパスを表示 | 引数がある |
| `ls` | 現在のフォルダ内容を表示 | 引数がある |
| `cd <folder>` | 子フォルダまたは`..`へ移動 | 対象なし、ファイルを指定 |
| `mkdir <name>` | 現在地にフォルダを作成 | 名前なし、同名あり、不正な名前 |
| `touch <name>` | 現在地に空ファイルを作成 | 名前なし、同名あり、不正な名前 |
| `cat <file>` | テキストファイルの内容を表示 | 対象なし、フォルダを指定 |
| `clear` | ターミナルの出力履歴だけを消去 | 引数がある |

### 入力ルール

- 前後の空白と連続する半角スペースは正規化する
- コマンド名は小文字のみ対応する
- `pwd`、`ls`、`clear`は引数を受け取らない
- その他は引数を1つだけ受け取る
- 名前には半角英数字、`.`、`_`、`-`を許可する
- 引用符、空白を含む名前、オプション、絶対パス、パイプ、リダイレクトは対象外
- 未対応コマンドには「まだ練習範囲に含まれていません」と表示する

## 5. レッスン構成

| Step | 目的 | 期待する入力 | 成功条件 |
|---:|---|---|---|
| 1 | ターミナルへの入力方法を知る | `pwd` | 現在地を表示した |
| 2 | フォルダの中身を確認する | `ls` | `welcome.txt`と`projects`を表示した |
| 3 | ファイルの内容を読む | `cat welcome.txt` | welcomeメッセージを表示した |
| 4 | フォルダへ移動する | `cd projects` | 現在地が`/home/learner/projects`になった |
| 5 | 練習用フォルダを作る | `mkdir practice` | `practice`フォルダが存在する |
| 6 | 作ったフォルダへ移動する | `cd practice` | 現在地が`.../projects/practice`になった |
| 7 | メモファイルを作る | `touch memo.txt` | `memo.txt`が存在する |
| 8 | 作成結果を確認する | `ls` | `memo.txt`を表示し、完了画面へ進んだ |

- 各ステップは、入力文字列だけではなく実行後の仮想状態で成功判定する
- 現在のステップ以外の有効なコマンドも実行できるが、進捗は成功条件を満たすまで進めない
- ヒントはボタン操作で表示し、最初から答えを常時表示しない

## 6. フィードバック

### 成功

- ターミナルにコマンド結果を表示する
- レッスン欄に、何が起きたかを1〜2文で説明する
- 自動で次のステップを表示する

### 失敗

- 入力した内容は履歴へ残す
- 技術用語だけに頼らず、原因と次の一手を示す
- 例: `command not found`だけで終わらせず、「そのコマンドはまだ使えません。今回は `ls` を試してください」と案内する

### 空入力

- 履歴へ追加せず、入力欄へフォーカスを戻す

## 7. 状態

保持する状態は次に限定します。

- 現在のステップ番号
- カレントディレクトリ
- 仮想ファイルシステム
- 画面に表示するコマンド履歴
- ヒントの表示状態
- コース完了状態

`localStorage`のキーは`terminal-first-steps-v1`とし、読み込み不能なデータは破棄して初期状態へ戻します。

## 8. リセット

- リセット操作前に確認を表示する
- 承認後、保存済み進捗、履歴、作成物、カレントディレクトリをすべて初期化する
- キャンセル時は状態を変更しない

## 9. レスポンシブ方針

- PCではレッスンとターミナルを上下に読みやすく配置する
- スマートフォンでは横スクロールを発生させず、入力欄を十分な高さにする
- ターミナル出力だけは長い文字列を折り返す
- ソフトウェアキーボード表示時も入力欄が見えるようにする

## 10. アクセシビリティ

- 入力欄に明示的なラベルを付ける
- 成功・失敗を色だけで区別しない
- ステップ更新とフィードバックを支援技術へ通知する
- リセットを除き、Enterキー中心で操作できる
- アニメーションはMVPでは必須にしない

## 11. 完了条件

- 8ステップを順番に完了できる
- 対応7コマンドが仕様どおり動作する
- 未対応・不正入力でも状態が壊れない
- 再読み込みとリセットが仕様どおり動作する
- PCとスマートフォン幅で主要操作が隠れない
